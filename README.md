# 奶龙合成

2048 玩法的奶龙恶搞合成游戏：滑动合并奶龙，等级越高表情越离谱，合成有音效！

- 🎮 在线游玩：<https://jie11122.github.io/nailong/>
- 🐉 12 个奶龙风恶搞表情（2 → 2048 → 4096+ 究极形态）
- 🔊 合成音效（Web Audio 实时合成，等级越高音调越高）+ 静音开关
- 📱 手机滑动 / 键盘方向键（WASD 也可）
- 🌐 单文件零依赖，加载后可离线游玩

## 本地运行

浏览器直接打开 `index.html`。

## 测试

```bash
node test-nailong.mjs
```
